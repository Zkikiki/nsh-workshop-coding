> 来源：用户提供的功能界面截图。部分字段因截图底部被遮挡或未完整截取，已标注为“未完整显示/待补充”。

## 1. 商店系统

### 1.1 功能概述

商店系统用于创建可打开的商品售卖界面。创作者可以配置多个商店、为商店添加商品，并设置商品的购买消耗、购买限制、解锁状态、购买后事件等。

从界面结构看，商店系统包含三层：

- **商店管理**：管理商店列表，创建/编辑商店。
- **商品管理**：在某个商店下管理商品列表。
- **属性编辑**：配置商品或商店本身的属性。

---

### 1.2 商店管理

#### 界面入口

左下角按钮：`商店管理`

#### 商店列表

| 字段/控件 | 说明 |
|---|---|
| 商店数量 | 当前已创建商店数量 / 最大商店数量，例如 `1/10` |
| `+` 添加商店 | 创建新的商店 |
| 商店卡片 | 显示商店名称，例如 `默认商店1` |
| 删除按钮 | 删除当前商店 |
| 复制/新增按钮 | 位于商店编辑区下方，疑似用于复制/新增商店 |
| 打开 | 打开当前商店的商品管理界面 |

---

### 1.3 商店编辑属性

用于配置某个商店本身的基础信息和打开/关闭逻辑。

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 商店名称 | 文本 | `默认商店1` | 商店显示名称 |
| 收到事件打开商店界面 | 事件 | 请输入事件 | 当收到指定事件时打开该商店界面 |
| 收到事件关闭商店界面 | 事件 | 请输入事件 | 当收到指定事件时关闭该商店界面 |
| 默认解锁 | 开关 | 关 / 开 | 商店是否默认解锁 |
| 单独显示 | 开关 | 关 / 开 | 是否单独显示该商店；可能用于控制商店入口或展示方式 |

---

### 1.4 商品管理

#### 界面入口

在商店界面中点击商品卡片，或点击“添加商店商品”。

#### 商品列表

| 字段/控件 | 说明 |
|---|---|
| 商品分类 | 当前商品分类，例如 `商店分类1` |
| `+` 添加分类/商品分类 | 新增商品分类 |
| 设置按钮 | 编辑商品分类配置 |
| 添加商店商品 | 创建新的商品 |
| 商品卡片 | 显示商品名称，例如 `默认商品` |
| 商品设置按钮 | 打开当前商品的属性编辑 |

---

### 1.5 商品编辑属性

#### 基础信息

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 商品名称 | 文本 | `默认商品` | 商品显示名称 |
| 商品描述 | 多行文本 | `我是商品的描述` | 商品说明文本，字数上限约 `50` |
| 商品图标 | 图标选择 | `+` | 设置商品图标 |
| 商品品质 | 下拉选择 | `白色品质` | 设置商品品质/稀有度 |
| 商品标签 | 文本 | `新品` | 商品标签，例如新品、限时等 |
| 显示排序 | 数值 | 请输入 `-1000~1000` 的值 | 控制商品在列表中的显示顺序 |
| 未解锁不显示 | 开关 | 关 / 开 | 未解锁时是否隐藏该商品 |

#### 购买消耗与获得

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 购买消耗指定属性 | 属性目标 | 目标 `(0/1)` | 设置购买商品时消耗的属性/货币。截图提示“商品必须填写属性消耗” |
| 购买商品消耗值 | 数值 | `1` | 每次购买消耗的属性数值 |
| 商品购买后获得背包物品 | 物品选择 | `+` | 购买商品后获得指定背包物品 |
| 获得商品后发出事件 | 事件 | 请输入事件 | 成功获得商品后触发事件 |

#### 购买限制与解锁

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 商品限购 | 数值 | `-1` | 商品总限购次数；`-1` 可能表示不限购 |
| 单次购买上限 | 数值 | 请输入 `1~9999999999` 的值 | 单次最多购买数量 |
| 默认解锁 | 开关 | 关 / 开 | 商品是否默认解锁 |

> 注：截图中“商品购买后获…”下方还有内容，但被截断/遮挡，需补充完整截图确认。

## 2. 属性系统

## 3. 背包系统

### 3.1 功能概述

背包系统用于创建背包容器和背包物品。可配置背包名称、描述、排序，以及物品的使用、拾取、丢弃、容量、堆叠、冷却、品质等逻辑。

系统包含两层：

- **背包管理**：创建/编辑背包。
- **背包物品管理**：在背包中创建/编辑物品。

---

### 3.2 背包管理

#### 背包列表

| 字段/控件 | 说明 |
|---|---|
| 背包数量 | 当前背包数量 / 最大背包数量，例如 `0/5` |
| `+` 添加背包 | 创建新的背包 |
| 背包卡片 | 显示背包名称，例如 `默认背包1` |
| 打开 | 进入该背包的物品管理 |
| 创建并打开 | 新建背包后直接打开 |

---

### 3.3 背包编辑属性

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 背包名字 | 文本 | `默认背包1` | 背包显示名称 |
| 背包描述 | 多行文本 | 请输入文字 | 背包说明文本，字数上限约 `200` |
| 显示排序 | 数值 | 请输入 `-10000~10000` 的值 | 控制背包显示顺序 |
| 创建并打开 | 按钮 | - | 创建背包并打开背包管理 |

---

### 3.4 背包物品管理

| 字段/控件 | 说明 |
|---|---|
| 背包分类 | 当前分类，例如 `背包分类1` |
| `+` 添加分类 | 新增背包分类 |
| 添加背包物品 | 创建新物品 |
| 物品卡片 | 显示物品名称，例如 `默认物品` |
| 物品设置按钮 | 打开物品编辑 |
| 物品编辑成功提示 | 保存后顶部出现 `物品编辑成功！` |

---

### 3.5 背包物品编辑属性

#### 基础信息

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 背包物品名字 | 文本 | `默认物品` | 物品显示名称 |
| 背包物品描述 | 多行文本 | `我是物品的描述` | 物品描述，字数上限约 `200` |
| 背包物品图标 | 图标选择 | `+` | 设置物品图标 |
| 物品品质 | 下拉选择 | `白色品质` | 设置物品品质/稀有度 |
| 工具栏优先级 | 数值 | 请输入 `0~99999` 的数 | 控制物品在工具栏中的优先级 |

| 收到事件禁止使用 | 事件 | 请输入事件 | 收到事件后禁止该物品使用 |

## 4. 科技树系统

### 4.1 功能概述

科技树系统用于创建可解锁的科技节点。每个科技可以配置名称、默认解锁状态、解锁事件、打开/关闭科技树界面的事件，以及玩家未解锁时的提示。

---

### 4.2 科技树管理

| 字段/控件 | 说明 |
|---|---|
| `+` 添加科技 | 新建科技节点 |
| 空状态提示 | `暂无内容，快去添加吧` |
| 科技卡片 | 显示科技名称；截图为空，仅显示“点击可新建科技” |

---

### 4.3 科技编辑属性

| 属性 | 类型/输入方式 | 默认值/示例 | 说明 |
|---|---|---|---|
| 科技树名字 | 文本 | 请输入文字 | 科技名称 |
| 默认解锁 | 开关 | 关 / 开 | 科技是否默认解锁 |
| 收到事件解锁 | 事件 | 请输入事件 | 收到指定事件后解锁科技 |
| 收到事件打开科技树界面 | 事件 | 请输入事件 | 收到指定事件后打开科技树界面 |
| 收到事件关闭科技树 | 事件 | 请输入事件 | 收到指定事件后关闭科技树界面 |
| 单独显示 | 开关 | 关 / 开 | 是否单独显示该科技 |
| 仅指定标记玩家可解锁 | 文本/标记 | 请输入文字 | 限制只有指定标记玩家能解锁 |
| 非标记玩家解锁时消息提示 | 文本 | 请输入文字 | 非指定玩家尝试解锁时显示提示 |
| 玩家未解锁科技时消息提示 | 文本 | 请输入文字 | 玩家尚未解锁时的提示文案 |
| 确认创建 | 按钮 | - | 保存并创建科技 |

## 5. 系统间可能的引用关系

| 系统 | 可引用/联动对象 | 说明 |
|---|---|---|
| 商店 | 属性系统 | 商品购买需要消耗指定属性，例如积分、金币 |
| 商店 | 背包系统 | 商品购买后可获得背包物品 |
| 商店 | 事件系统 | 商店打开、关闭、购买成功等都可通过事件触发 |
| 背包 | 属性系统 | 使用物品后可改变属性 |
| 背包 | 事件系统 | 获得、使用、拾取、禁用、恢复使用等都可通过事件联动 |
| 科技树 | 事件系统 | 可通过事件解锁、打开、关闭 |
| 科技树 | 玩家标记 | 可限制特定标记玩家解锁 |
