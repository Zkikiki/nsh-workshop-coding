# 创意代码教程补充笔记

来源目录: `教程/`

本文件整理教程中的已验证思路，用于补充 `coding-guide.md` 和 `blocks-by-type.md`。原教程文本来自导出/转写，部分原文有编码/OCR 噪声，因此这里记录可明确理解的工作流，不补造未出现的参数槽位。

## 1. 全局画布与组件画布

来源: `教程/第一期全局画布和组件画布.txt`

### 画布职责

- 全局画布: 承载整个关卡的整体逻辑和全局规则。
- 组件画布: 更像可复用的功能模块，封装在单个组件上使用。
- 组件画布需要导出变量/功能后挂载到具体组件上，才能对该组件生效。

### 变量访问关系

- 组件画布可以直接使用全局画布中的变量和函数。
- 全局画布不能直接读取组件画布内部变量。
- 如果全局画布需要读取某个组件画布里的数值，使用 `获取画布变量值` 这类取值能力。

### 复制组件注意

- 复制带有组件画布的组件时，画布逻辑会随组件复制。
- 复制后，组件关联绑定需要重新确认，例如交互区域、公告牌、触发器或其他场景对象与画布变量的绑定。

## 2. 创建组件

来源: `教程/创意代码第二期《创建组件》_导出.txt`

### 创建组件的两种方式

- 使用组件模板创建组件。
- 使用场中选择创建组件。

使用组件模板前，需要先把目标组件导出到模板库。使用场中选择时，场景里必须存在该组件；如果被引用的场中组件已经销毁，对应逻辑可能无法正常执行。

### 随机创建组件

常见结构:

```text
事件: 游戏开始
  - 控制: 重复执行 N 次
    - 行为: 使用组件模板创建组件
      - 组件模板: 指定模板或随机模板
      - 指定位置: 获取范围内随机点
```

用于在指定范围内随机刷出多个组件。

### 多模板随机

如果希望随机刷出不同类型组件:

```text
准备变量
- 模板列表，类型: 列表
- 列表元素类型: 组件模板

逻辑
- 给模板列表添加多个组件模板
- 创建组件时，组件模板槽使用 `获取列表随机值（组件模板）`
```

## 3. 创建后保存组件引用

来源: `教程/逆水寒创意代码第三期《销毁组件-应用》_导出.txt`

创建组件行为右侧可通过“获取变量”得到新创建组件的返回值，并把它作为取值块使用。

常见用途:

```text
事件: 玩家触发指定交互键
  - 行为: 使用组件模板创建组件
    - 位置: 获取当前组件位置
    - 获取变量: 新组件
  - 行为: 设置变量 金币 = 新组件
```

如果需要管理多个动态创建物:

```text
准备变量
- 所有金币，类型: 列表
- 列表元素类型: 组件

每次创建金币后
- 行为: 添加列表元素
  - 列表: 所有金币
  - 元素: 新创建金币
```

## 4. 组件销毁与存在性判断

来源: `教程/逆水寒创意代码第三期《销毁组件-应用》_导出.txt`

### 销毁自身

- `销毁自身` 只在组件画布中生效。
- 在组件画布逻辑中，`销毁自身` 后面的内容不会继续执行。
- 因此 `销毁自身` 应放在当前逻辑的最后。

### 列表中保存的组件可能已销毁

动态组件销毁后，如果它的引用仍保存在列表里，后续对它执行移动等操作可能报错。

处理方式:

```text
控制: 列表元素依次执行
  - 控制: 如果 [对象是否存在 当前元素]
    - 行为: 对当前元素执行移动/设置/销毁等操作
```

这是处理动态创建物、可拾取物、弹出物、吸附物时的重要防错模式。

## 5. 动态组件移动示例思路

来源: `教程/逆水寒创意代码第三期《销毁组件-应用》_导出.txt`

教程中示例了从箱子交互后创建金币，并让金币向外弹出:

```text
事件: 玩家触发指定交互键
  - 行为: 使用组件模板创建组件
    - 位置: 获取当前组件位置
    - 获取变量: 金币
  - 行为: 移动到目标点
    - 对象: 金币
    - 目标点: 根据金币位置与玩家位置计算出来的偏移点
```

其中用到了向量思路: 通过金币位置与玩家位置的差值，得到远离玩家的方向，再用方向偏移点作为目标点。

参数细节以工坊实际积木槽位为准。

## 6. 技能事件联动动态组件

来源: `教程/逆水寒创意代码第三期《销毁组件-应用》_导出.txt`

教程中示例了技能发出事件后，全局画布监听该事件，并让所有金币移动到玩家位置:

```text
事件: 收到事件 技能发出事件
  - 控制: 列表元素依次执行 所有金币
    - 控制: 如果 [对象是否存在 当前金币]
      - 行为: 移动到目标点
        - 对象: 当前金币
        - 目标点: 当前触发玩家的位置
```

要点:

- 技能可作为事件来源。
- 事件触发者/来源可用于找到对应玩家。
- 对列表中的动态组件操作前，先判断对象是否存在。
